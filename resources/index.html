SECURITY KNOWLEDGE / TOOL LIBRARY

Cybersecurity resources.

Ten practical tool guides for learning how to test, monitor, inspect and investigate systems. Pick a tool below to open its dedicated guide.

Use responsibly. These guides are educational references. Run testing tools only against systems you own, isolated labs, or targets for which you have explicit authorization. Tool categories here reflect each tool's primary role in this library, not every possible use.

Each card gives you the core purpose, the security problem it helps address, and a few concepts to look for in the guide. Use Quick concept to reveal an extra learning cue; the important description and guide link remain visible without flipping or hovering.

01 / OFFENSIVE SECURITY

Red Teaming

Tools for authorized discovery, manual web testing, path enumeration, controlled vulnerability validation and password-audit labs.

05 TOOLS
01
NETWORK DISCOVERY

Nmap

Nmap helps map reachable hosts and exposed network services so an analyst can build an evidence-based picture of an authorized lab's attack surface.

SECURITY PROBLEMWhat hosts and network services are visible from this testing location?
Host discoveryTCP / UDPService detection
Quick concept

A port state is a report about what Nmap could observe from one network position; it is not a verdict that a service is vulnerable.

02
WEB APPLICATION TESTING

Burp Suite Community Edition

Burp's intercepting proxy lets a tester inspect browser-to-application traffic and repeat carefully modified requests against a test application.

SECURITY PROBLEMHow does the application process a request, its parameters, session and response?
Proxy historyRepeaterHTTP / WebSockets
Quick concept

Community Edition includes the manual proxy workflow and Repeater; the full scanner and full Intruder attack capability are Professional features.

Explore tool →Official docs ↗
03
CONTENT ENUMERATION

Gobuster

Gobuster tests candidate paths or names against a defined target and helps identify content or virtual hosts that are not linked in normal navigation.

SECURITY PROBLEMWhich expected or undocumented paths respond on an in-scope test web server?
Directory modeWordlistsHTTP status
Quick concept

A response code is a clue, not proof that a path contains sensitive data; wildcard routes and custom error pages can generate misleading results.

04
CONTROLLED VALIDATION

Metasploit Framework

Metasploit organizes modules that support security research and controlled lab validation of known weaknesses after a finding has been investigated.

SECURITY PROBLEMCan a suspected lab vulnerability be safely reproduced and its impact understood?
ModulesAuxiliaryLab validation
Quick concept

A module's existence does not confirm a target is vulnerable. Version, configuration, prerequisites and safe validation all matter.

05
AUTHENTICATION AUDITING

Hydra

THC Hydra can support authorized password-auditing exercises against deliberately configured lab services to explore authentication controls.

SECURITY PROBLEMDo lab authentication controls resist weak credentials and unsafe retry policies?
AuthenticationRate limitsAudit scope
Quick concept

Use a test account and deliberately small input set. Lockout, monitoring, authorization and operational impact are part of the lesson.

02 / DEFENSIVE SECURITY

Blue Teaming

Tools for packet-level analysis, endpoint and log monitoring, network intrusion detection, and structured network-activity investigation.

05 TOOLS
01
PACKET ANALYSIS

Wireshark

Wireshark decodes packet captures into protocol details, helping analysts troubleshoot network behavior and investigate suspicious traffic.

SECURITY PROBLEMWhat can packet-level evidence show about a conversation or unexpected protocol behavior?
PCAPDisplay filtersTCP / DNS
Quick concept

Capture filters limit what is collected; display filters only change what is shown. Encrypted payloads generally remain unreadable without authorized decryption material.

Explore tool →Official guide ↗
02
ENDPOINT MONITORING

Wazuh

Wazuh centralizes configured endpoint and log data, applies analysis rules, and presents alerts that help analysts prioritize investigation.

SECURITY PROBLEMWhich collected events deserve triage, correlation and a documented response?
AgentsLog analysisFile integrity
Quick concept

An alert is a detection signal generated from available telemetry and rules; an analyst still has to validate context and decide whether an incident is confirmed.

Explore tool →Official docs ↗
03
NETWORK IDS / IPS

Suricata

Suricata inspects traffic against configured signatures and protocols, producing events or alerts that support network detection and response.

SECURITY PROBLEMDoes observed traffic match a rule or protocol pattern that warrants investigation?
RulesIDS / IPSEVE JSON
Quick concept

A signature match is evidence to investigate, not automatically a confirmed intrusion; rule quality, traffic visibility and tuning affect results.

Explore tool →Official docs ↗
04
NETWORK SECURITY MONITORING

Zeek

Zeek turns observed network activity into structured logs and events that analysts can correlate across connections and protocols.

SECURITY PROBLEMWhat communication patterns and protocol metadata can be extracted from the traffic a sensor sees?
conn.logDNS / HTTPMetadata
Quick concept

Zeek commonly produces structured records rather than a GUI packet-by-packet view. Sensor placement and encryption determine what it can observe.

Explore tool →Official docs ↗
05
WINDOWS ENDPOINT TELEMETRY

Microsoft Sysmon

Sysmon records selected Windows system activity to the Event Log, giving investigators richer process and other endpoint evidence when configured.

SECURITY PROBLEMWhich process, file, network or configuration events help explain endpoint behavior?
Event IDsProcess creationTelemetry
Quick concept

Sysmon generates telemetry, not a final verdict. Event availability depends on version and configuration; collection and analysis happen elsewhere.
