### Writeup topics

The writeups section is organized to make hands-on work easy to explore. It includes a dedicated [Hack The Box](https://roger-rached.github.io/writeups/htb/) area, with [Starting Point](https://roger-rached.github.io/writeups/htb/starting-point/) material, and is intended to grow with additional lab writeups and security research.

Topics covered across the portfolio include:

- **Network and infrastructure security** — enumeration, service analysis, network protocols, and device hardening.
- **Linux and Windows environments** — host enumeration, initial access, privilege escalation, and post-exploitation concepts in lab environments.
- **Web and API security** — authentication, authorization, input handling, and common application vulnerabilities.
- **AI security** — LLM and agent security, AI red teaming, and emerging attack surfaces.
- **Security operations** — monitoring, alert analysis, and defensive security concepts.

## Run locally

Because the site is static, you can preview it with a local HTTP server:

```bash
git clone https://github.com/Roger-Rached/Roger-Rached.github.io.git
cd Roger-Rached.github.io
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.

You can also use the VS Code Live Server extension or another static HTTP server.
