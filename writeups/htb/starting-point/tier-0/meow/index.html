01 — Meow.

Very Easy · Linux · Telnet

VERY EASY LINUX TELNET ENUMERATION AUTHENTICATION
01 — ENUMERATION

Quick Nmap check

I began with a basic Nmap scan to establish the target's attack surface. The goal was to identify which ports were exposed, determine the services listening on them, and decide where further enumeration would be most useful. 

nmap -sC -sV <TARGET_IP>

Initial Nmap enumeration of the target.

FINDING

Telnet was discovered open on port 23.

02 — CREDENTIAL TESTING

Unzip wordlist

I prepared the password wordlist for credential testing against the exposed Telnet service. 

unzip rockyou.txt.zip

Extracting the wordlist before credential testing.

03 — HYDRA

Brute-forcing Telnet on port 23

With Telnet exposed on port 23, I tested the authentication mechanism using Hydra.

Telnet brute-force attack using a blank password

Hydra testing Telnet authentication. 

hydra -l [username] -e n <TARGET_IP> telnet

The -e n option tells Hydra to try a null or blank password for every username being tested.

Example 

hydra -l [username] -P /path/to/passwords.txt <TARGET_IP> telnet

Blank username 

hydra -l "" -P /path/to/passwords.txt <TARGET_IP> telnet

Alternative 

hydra -e n -P /path/to/passwords.txt <TARGET_IP> telnet
-e n · NULL PASSWORD -e s · USERNAME AS PASSWORD

-e n tells Hydra to try a blank password.
-e s tells Hydra to try the username as the password.

04 — ACCESS

Telnet access

After identifying the exposed Telnet service, I connected to the target and tested the authentication path. 

telnet <TARGET_IP> 23

The machine demonstrates how an exposed remote service combined with weak or default authentication can provide direct access to a system.

05 — ROOT ACCESS

Verifying access

Once access was obtained, I verified the current user and inspected the filesystem for the flag. 

whoami
ls
cat flag.txt

No separate privilege-escalation step was required because the authentication path provided the required level of access.

06 — WHAT I LEARNED

Lessons from Meow

Meow reinforced the importance of starting with enumeration instead of immediately searching for complex exploits.

A single exposed service can become the primary attack surface when authentication is incorrectly configured. Understanding what is exposed and how it is configured is often more important than immediately reaching for advanced exploitation.
