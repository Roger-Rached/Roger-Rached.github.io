02 — Fawn.

Very Easy · Linux · FTP

VERY EASY LINUX FTP ENUMERATION ANONYMOUS ACCESS
01 — ENUMERATION

Quick Nmap scan

I started with an Nmap scan to identify the exposed ports and services on the target. The goal was to establish the initial attack surface and determine which service required further enumeration. 

nmap -sC -sV <TARGET_IP>

Nmap scan showing the exposed FTP service.

FINDING 01

FTP was discovered running on port 21.

02 — FTP

Anonymous FTP access

FTP was exposed on port 21, so I moved from general enumeration to service-specific testing. One of the first checks I made was whether the server permitted anonymous authentication, since a misconfigured FTP service can expose files without requiring a legitimate user account. 

ftp <TARGET_IP>

The server accepted the anonymous FTP session, confirming that anonymous authentication was enabled.

FINDING 02

The FTP server allowed anonymous login.

With anonymous access confirmed, I enumerated the accessible directory contents to determine whether files could be read from the exposed FTP share.

03 — FILE ACCESS

Accessing the FTP share

After authenticating anonymously, I enumerated the available files and found the accessible flag file. I then retrieved it directly through the FTP session. 

ls
get flag.txt

Anonymous FTP access and flag retrieval.

FINDING 03

The anonymous FTP session provided access to the target's files, including the flag.

04 — WHAT I LEARNED

Lessons from Fawn

Fawn reinforced the importance of identifying exposed services before attempting more complicated attacks. The initial Nmap scan immediately narrowed the assessment down to FTP, allowing the enumeration to become service-specific.

FTP can expose files and functionality that should never be publicly accessible. Anonymous authentication is therefore an important configuration issue to test whenever FTP is discovered during enumeration.

In this case, no sophisticated exploitation was required. A misconfigured authentication control was enough to provide access to files on the server.

05 — TOOLS & TECHNIQUES

Tools used

The main tools and techniques used during the exercise were:

  • Nmap — service enumeration.
  • FTP client — interacting with the exposed file-transfer service.
  • Anonymous authentication — identifying unauthenticated access.
